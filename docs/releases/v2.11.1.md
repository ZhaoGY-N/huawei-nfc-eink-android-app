QPollLab v2.11.1 正式版，包含 Shizuku Shell / Root 统一后端、可选 SN220 HAL 注入适配、色阶测试图，以及连续选图和重复裁切修复。

## 更新

- 修复重新选择另一张图片后应用裁切可能不更新预览和发送快照的问题。
- 重复裁切始终使用完整原图，并恢复上次应用的位置与缩放，可以重新扩大范围或选择其他区域；取消编辑不会改变已应用的裁切。旋转后重新裁切使用对应方向的原图并重置窗口。
- 统一通过 Shizuku UserService 管理 Shell / Root 后端；Root 负责底层准备，NFC 通信使用 Shell 身份。
- 新增默认关闭的“SN220 Q-Poll 兼容”实验选项，支持 `nfc_nci` 命名族正则识别、`write_internal` / `write_unlocked` 路径及会话恢复诊断。需要以 Root 启动 Shizuku 和 arm64 设备。
- 新增色阶测试图，包括灰阶、黄色/红色色阶、连续渐变及四色基准，方便比较图像处理和实物效果。
- 支持手动选择 A0 / A1 屏幕布局；D1 C0 字段支持已登记的完整值 `201EA001` / `00000001`。

## 安装

下载附件 APK 覆盖安装，重新打开应用并连接 Shizuku。通过 Magisk / KernelSU 授予权限后，可使用 Shizuku Root；常规寻卡保持默认设置，仅需要注入适配时启用 SN220 实验选项。刷新前选择与屏幕一致的 A0 / A1 类型。

## 验证与兼容范围

- Java 协议、图像处理、面板布局、连接恢复、权限及裁切回归检查通过；APK 构建与签名验证通过。
- 用户已在 USB 连接的实机上确认连续选图及同图重复裁切修复有效。此前已在 Xiaomi 25102RKBEC / myron（SN220U）验证注入通信，用户反馈成功。
- SN220 注入仍为实验功能，不保证所有 SN220 / ROM 通用兼容，fork 作者设备尚未在本分支实机回归。此前记录的某轮刷新最终返回供能错误 `68CA`，因此不能据此声称已验证所有设备上的完整忙→空闲周期。
- 注入只修改 HAL 进程内存，不修改 NFC 固件、系统 HAL 文件或屏幕 DB / DA；兼容库驻留至 HAL 进程重启，正常会话结束关闭改写。

附件包含 APK 及 SHA-256 校验文件。
